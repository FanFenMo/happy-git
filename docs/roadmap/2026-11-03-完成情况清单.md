## 清单的状态怎样理解

“已实现，待本版验收”表示当前调用链或函数确实存在；“有历史验证”只表示保存了旧时间、旧范围的记录；“设计完成，未实现”表示具备实施说明但没有对应业务模块；“未完成”表示尚不能交付该能力。下面每一项同时给出证据和剩余工作，后续可以逐项更新。

## 下一次更新清单时怎样算完成

每项应补上实现提交、合入 develop 的提交、输入/数据来源、验证时间及结果、产物或运行记录路径。只有实现与对应业务验收都成立，才可标“已完成”。需要 GitHub 真实写入的操作单独取得执行范围；仅推荐读取、数据库隔离验证和本机重排不混进真实 Star 验收。
