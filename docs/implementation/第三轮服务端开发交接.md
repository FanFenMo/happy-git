学习任务新增按命名空间、任务 ID、已观察到的 attempt 和原因执行取消与接续。运行中的任务由原 worker 检查租约并结束自己提交的作业，发布前再次核对；重试创建关联原任务的新任务和独立输出目录，旧失败和取消记录保留。业务推断队列支持取消及后续调度，管理台提供对应任务操作。服务运行工具只操作节点清单声明且明确选定的单元。
