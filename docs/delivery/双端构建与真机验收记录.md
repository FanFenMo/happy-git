## 一、构建链与公开配置代际对齐改动

本轮针对第二轮之后双端发布链路中的代际不一致与配置断层完成了系统修复：

1. **修复公开地址预置脚本断层（`client/scripts/prepare-config.mjs`）**：
   - 修复原 CLI 入口无参调用 `writeNativeConfigs()` 导致始终输出空 `apiBaseUrl` 的问题；
   - 现在构建期按 `public-config.json` → `.env*` → `VITE_API_BASE_URL` 优先级解析单一公开 HTTPS 服务地址，在发布模式拒绝空值、本地回环地址（`localhost`/`127.0.0.1`/`10.0.2.2`）、非 HTTPS、凭据、查询参数与 hash；
   - 同步输出仅含非敏感字段的 `electron/config.generated.json`、`android/app/src/main/res/values/happygit_config.xml` 及双端 `release-metadata.json`（绑定 `appVersion`、`gitCommit`、`apiBaseUrl`、`apiContractVersion`、`sqliteSchemaVersion`、`builtAt`）。
2. **打通双端原生 `CloudService` 自动读取预置地址**：
   - Windows（`client/electron/cloud-service.cjs`）：自动读取随包内置的 `electron/config.generated.json`，优先级为 `显式测试参数 > 开发自定义设置 > 环境变量 > 预置 config.generated.json > 本地开发回退`；
   - Android（`CloudService.java`）：自动读取构建期生成的字符串资源 `happygit_api_base_url`，普通用户安装后零配置、不输入 API 地址或任何密钥。
3. **统一版本号与产物摘要校验链**：
   - 同步对齐 `client/package.json`（`1.2.0`）、`client/android/app/build.gradle`（`versionCode 3`, `versionName "1.2.0"`）、`client/src/components/SettingsModal.vue`（`v1.2.0`）、`client/scripts/build-win.mjs` 与 `.github/workflows/build-apk.yml`；
   - 新增 `client/scripts/generate-release-manifest.mjs`，为最终 Windows 压缩包/EXE 与 Android APK 自动生成 `.sha256` 校验文件及 `release-manifest-<platform>.json`（绑定提交号、版本号、公开服务地址、契约版本与文件摘要）。

## 二、标准构建与摘要生成命令

> 维护者在具备 Node.js 24、`client/node_modules`、JDK 21 与 Android SDK 的构建机或 GitHub Actions（`.github/workflows/build-apk.yml`）中执行以下命令；普通用户无需操作。

### 1. Windows 桌面端（`.exe` / `.zip`）
```powershell
cd client
npm ci
$env:VITE_API_BASE_URL = "https://<正式公开业务域名>"
npm run build:win
# 如需单独对压缩包生成 .sha256 与 release-manifest-windows.json：
node scripts/generate-release-manifest.mjs `
  --platform windows `
  --artifact ..\output\HappyGit-v1.2.0-win-x64.zip `
  --output ..\output\release-manifest-windows.json `
  --build-command "cd client && npm run build:win"
```

### 2. Android 移动端（`.apk`）
```bash
cd client
npm ci
export VITE_API_BASE_URL="https://<正式公开业务域名>"
npm run build:release
npx cap sync android
cd android
./gradlew assembleDebug --no-daemon
node ../scripts/generate-release-manifest.mjs \
  --platform android \
  --artifact app/build/outputs/apk/debug/app-debug.apk \
  --output ../../output/release-manifest-android.json \
  --build-command "cd client && npm run build:release && npx cap sync android && cd android && ./gradlew assembleDebug --no-daemon"
```
