## 一、本轮核心完成项

### 1. 真实采集目录多批接入与来源登记（`tools/datasets/`）
- 响应第二轮集中验收记录（`docs/validation/2026-11-17-round-two-integration.md`）提出的数据接入需求，在 [build_dataset.py](../../tools/datasets/build_dataset.py) 新增：
  - `--repo-catalog <文件或目录>`（可重复传参）：支持直接扫描成员甲导出的多批公开仓库 JSONL 目录，按 `repoId` 保留较新 `observedAt` 去重并统计原始行数、重复数、非空 README 数与源文件 SHA-256；
  - `_select_stratified_repositories`：当真实公开仓库超出目标规模时按领域与热度分层确定性抽样；
  - `--behavior-source-mode deterministic_rules|llm_synthesized|real_observed`：在 `provenance.jsonl` 与 `dataset-manifest.json` 中显式区分行为来源。
- 新增单元测试 `test_multi_file_real_catalog_dedup_and_stratified_freeze` 并通过 `validate_dataset(..., strict_real=True)` 校验。

### 2. 独立画像对比运行器、成员甲导出适配、20×3 波动与 SVG 图表（`tools/experiments/`）
- **无缝对接成员甲第三轮 `learning-export`**：在 [run_experiment.py](../../tools/experiments/run_experiment.py) 新增 `--server-export-dir`，自动校验 `run-manifest.json` 的 `state == "completed"` 及 `baseline.jsonl` / `learned.jsonl` 的 SHA-256，将服务端固定基线（`baseline_mr_fixed_v1`）、B 本地基线（`baseline_local_v1`）、首版学习模型（`learned_model`）、回流版模型（`--extra-model`）与通用大模型（`llm_reference`）清晰分开报告。
- **空分布独立评分与失败分组合计**：在 [metrics.py](../../tools/experiments/metrics.py) 中单独统计空分布精确率（不将空向量补成均匀向量），在 `overall`、`byScenario`、`bySourceKind`、`bySparsity` 中同时记录样本数与失败数，并新增 `compute_method_comparison_deltas`（改进/退化/持平或不确定计数）。
- **固定 20 用户×总计 3 次独立调用协议**：无条件导出冻结子集清单 `repeat-subset-ids.json`；执行 `--run-llm-api` 时主流程计为第 1 次调用、子集补跑 2 次共 3 次独立调用，保存 `provider`、`calledAt`、`modelIdentifier`、`promptVersion`、`promptDigest`、`requestParams`、`evidenceHash`、`rawResponse`、`elapsedMs` 与失败记录，输出波动均值/标准差/极值与状态一致率。
- **4 类匿名盲评工作表与自动解盲**：同步导出 `blind-review-sample.jsonl`、`blind-review-key.json`、`blind-review-worksheet.md` 与 `blind-review-audit-template.jsonl`（四类：`grounded`、`over_inferred`、`nonexistent_citation`、`insufficient_evidence`），支持 `--blind-audit-file` 解盲汇总且保护既有 `blind-review-key.json` 不被覆写。
- **零依赖 SVG 图表**：新增 [render_charts.py](../../tools/experiments/render_charts.py)，自动渲染整体指标、分场景 F1 与分稀疏度（含 `empty`/`sparse`/`medium`/`dense`）三类 SVG 图表并嵌入 `report.md`。
- **实际基准验证产物**：基于确定性标准规模（10,000 合成夹具仓库、100 位 test 用户、20 万浏览事件，全部 8 项红线校验通过）跑通 `standard` 基线评测，保存于 [tools/experiments/generated/standard-round3-baseline-preview/](../../tools/experiments/generated/standard-round3-baseline-preview/report.md)（另含 5 用户 `pilot-round3-preview`）。
